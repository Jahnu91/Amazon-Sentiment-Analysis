# 🛍️ Amazon Review Sentiment Analysis using Python

## 📌 Project Overview

This project performs **Sentiment Analysis** on Amazon shopping reviews using **Python**, **Natural Language Processing (NLP)**, and **Machine Learning**. It classifies customer reviews into **Positive**, **Neutral**, and **Negative** sentiments and visualizes the results using different charts.

---

## 🎯 Objectives

- Analyze customer opinions from Amazon reviews.
- Classify reviews into Positive, Neutral, and Negative.
- Visualize sentiment distribution using graphs.
- Train a Machine Learning model to predict review sentiment.

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- TextBlob
- Scikit-learn
- Matplotlib
- Seaborn
- WordCloud
- KaggleHub

---

## 📂 Dataset

**Dataset Source:**
Amazon Shopping Reviews (Daily Updated)

The dataset is downloaded using **KaggleHub** and contains customer reviews along with product-related information.

---

## ⚙️ Project Workflow

1. Import required libraries
2. Load Amazon review dataset
3. Remove duplicate records
4. Handle missing values
5. Generate sentiment labels using TextBlob
6. Visualize sentiment distribution
7. Convert text into TF-IDF features
8. Train Logistic Regression model
9. Evaluate model performance

---

## 📊 Visualizations

The project generates:

- 📈 Bar Chart

## 🤖 Machine Learning Model
